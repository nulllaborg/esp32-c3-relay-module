Key Operating Modes
1. Type-C Powered: Connect an ESP32-C3 and power the setup directly via the Type-C USB port. The onboard socket connects directly to the ESP32-C3's 5V, GND, D1, and D2 pins (power supply and dual-channel relay control signals).
2. Terminal Powered: Connect an ESP32-C3 and power via the 5V screw terminal block.
3. External Microcontroller Use: Connect directly to other controllers using the standard PH2.0-4Pin interface (Support 3.3V /5V).
4. Sensor Expansion Mode: Plug in an ESP32-C3 while utilizing extra header pins to connect external sensors (e.g., temperature, motion, or light sensors).
